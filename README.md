# Real-Estate-Sales-Property-Management-System
Salesforce-based Real Estate Sales and Property Management System with property records, customer bookings, sales tracking, and automated workflows.
Real Estate Sales & Property Management System

Project Overview
This project is developed using Salesforce to manage real estate properties, customer bookings, and property sales in one place.

Objectives
- Maintain property details and availability.
- Manage customer information.
- Track property bookings and sales.
- Automate property status updates using Salesforce Flows.
- Generate reports for property and sales management.

Technologies Used
- Salesforce Developer Edition
- Salesforce Lightning Experience
- Custom Objects and Fields
- Salesforce Flow Builder
- Reports and Dashboards

Main Modules
1. Properties: Stores property details, prices, locations, and availability status.
2. Bookings: Tracks customer bookings and booking status.
3. Property Sales:Records sale dates, amounts, and sale status.
4. Contacts: Maintains customer information.
5. Automation: Updates property status when a booking is confirmed.
6. Reports and Dashboards: Summarizes property, booking, and sales data.
